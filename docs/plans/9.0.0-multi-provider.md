## Feature Plan: LokiBulkDataProcessor 9.0.0 — multi-provider Core, SQL Server and Oracle

Research basis: I read every file in `LokiBulkDataProcessor/` and the integration test base, csprojs, CI, README upgrade table, `docs/plans/oracle-bulkcopy-spike-findings.md`, and issues #11–#17 (via the REST API). I also checked NuGet: EF Core 10.0.x depends on `Microsoft.Data.SqlClient` 6.1.1; MDS 7.x is a new major that moved Entra auth into a separate package. Reflecting over the spike's `Oracle.ManagedDataAccess.dll` confirmed `ArrayBindCount`, `ArrayBindRowsAffected`, `OracleDbType.Boolean/IntervalDS/BinaryDouble/TimeStampTZ`, `ExecuteNonQueryAsync`, `DestinationSchemaName` and `OracleBulkCopyColumnMapping`. I made no changes to the repo.

### Summary
- Split the library into three packages that always share the same version, 9.0.0:
  - **`LokiBulkDataProcessor.Core`** (new) holds everything that doesn't depend on a database: `IBulkProcessor`, `IBulkProcessorFactory`, the mapping API, the JSON reader, the shared pipeline and the provider SPI.
  - **`LokiBulkDataProcessor`** (same package id) becomes the SQL Server provider on `Microsoft.Data.SqlClient`. It keeps the old one-line `AddLokiBulkDataProcessor(connectionString, …)` registration.
  - **`LokiBulkDataProcessor.Oracle`** (new) uses array-bind INSERT by default. Direct-path `OracleBulkCopy` is opt-in.
- Every input shape is converted to an `IDataReader` plus a list of `ColumnMap`. One pipeline then handles connection, transaction, write, translate and dispose. This removes the three duplicated command copies and closes #11, #12, #13, #15 and #16 in one place.
- The factory is `IBulkProcessorFactory` (singleton, mockable). It creates independent processors from a string provider name, for example `factory.Create("Oracle", cs)`. Seedr's `DatabaseEngine.ToString()` already gives `"SqlServer"` / `"PostgreSql"`.
- Postgres is not built in this release. The SPI is shaped so Npgsql `BeginBinaryImport` fits without changes (details under Key code samples).

**Type forwarders: yes, keep them.** `[assembly: TypeForwardedTo]` in the SQL assembly lets assemblies built against 8.x bind to Core at runtime. The common case is a consumer's separate "Mappings" class library that only subclasses `ModelMapping<T>` / `DataMapping`. It costs about 10 attribute lines. Source compilation needs no forwarders, because Core comes in transitively with the same namespaces. Forwarders don't save 8.x binaries that call `SaveAsync`, since that signature changed and they'll get `MissingMethodException`; the upgrade guide says so. Keep them through 9.x and decide again for 10.0.

### Bug fixes included
| Issue | Plan step | How it's fixed |
|---|---|---|
| #11 per-call settings leak through the singleton `AppContext` | Step 4 | `AppContext` is deleted. Mappings live in an immutable singleton `MappingRegistry`. `Transaction`/`BatchSize`/`Timeout` live on a `BulkProcessorSettings` owned by each processor (one per `Create` call; scoped under the legacy registration). Each call works from a `BulkCallSettings` snapshot, so changing a setting mid-flight doesn't affect a running call. Tests: two DI scopes, and two factory processors. |
| #12 external transaction rolled back; rollback failure hides the original error | Step 4 | `ConnectionScope.RollbackAfterFailureAsync`: if the transaction is the caller's, Loki only logs a warning and never touches it. If it's Loki's own, Loki rolls back inside try/catch, logs any rollback failure with `LogError`, and the pipeline rethrows the original with `throw;`. |
| #13 connection/transaction leak on failure | Step 4 | `await using ConnectionScope` disposes Loki's own transaction and connection on every path. `OpenAsync` disposes the connection if `Open` or `BeginTransaction` throws. The writer is `await using`. Readers Loki creates (ObjectReader, DataTableReader, JsonDataReader) are disposed by `BulkSource`; caller readers are not. |
| #14 deprecated `System.Data.SqlClient` | Step 2 | Switch to `Microsoft.Data.SqlClient` 6.1.8 (same major line as EF Core 10, so consumers aren't forced onto MDS 7). `AdoptExternalTransaction` throws `ArgumentException` naming the wrong type. Integration test with `dbContext.Database.BeginTransactionAsync()` + `GetDbTransaction()`. |
| #15 original exception discarded | Steps 4, 6 | `IBulkCopyProvider.TranslateException` must return a new exception with `InnerException = original`, and the pipeline enforces this. The SQL translator keeps the documented column-mapping message. Oracle maps by `OracleException.Number`. |
| #16 inconsistent mapping lookup | Step 4 | One rule. A `DataMapping` applies when `SourceTableName` equals the input's **source name**. The source name is: the explicit `sourceName` argument (IDataReader overload), otherwise `DataTable.TableName` if not blank, otherwise the **destination table name** (which is also the rule for JSON and for readers without `sourceName`). Implemented once in `MappingKey.For`; documented in XML docs and README. Today's working paths keep their behaviour. |
| #17 Testcontainers in the library | Step 1 | Removed from the library and UnitTests csprojs. The CI `pack` job checks `dotnet list package --include-transitive` contains no Testcontainers. |

**Core SPI** (`LokiBulkDataProcessor.Core/Providers/`)
```csharp
namespace Loki.BulkDataProcessor.Providers;

/// <summary>A database engine that Loki can bulk-copy into. Implementations must be stateless and thread-safe.</summary>
public interface IBulkCopyProvider
{
    /// <summary>Registered name used by <see cref="IBulkProcessorFactory.Create"/> (case-insensitive).</summary>
    string Name { get; }

    /// <summary>Creates a new, unopened connection. Loki opens, owns and disposes it.</summary>
    DbConnection CreateConnection(string connectionString);

    /// <summary>Validates and returns a caller-owned transaction as this provider's type.
    /// Throws <see cref="ArgumentException"/> when the transaction belongs to another driver.</summary>
    DbTransaction AdoptExternalTransaction(IDbTransaction transaction);

    /// <summary>Creates a writer bound to an open connection and its active transaction.</summary>
    IBulkWriter CreateWriter(BulkWriteContext context);

    /// <summary>Returns a NEW exception whose InnerException is <paramref name="exception"/>.</summary>
    Exception TranslateException(Exception exception, BulkWriteTarget target);
}

/// <summary>Writes one source into one destination table inside the context's transaction.</summary>
public interface IBulkWriter : IAsyncDisposable
{
    /// <remarks>Implementations may complete synchronously. Oracle direct-path mode blocks the calling
    /// thread because ODP.NET has no asynchronous direct-path API; cancellation is checked only before the load starts.</remarks>
    Task WriteAsync(IDataReader source, BulkWriteTarget target, CancellationToken cancellationToken);
}

public sealed record ColumnMap(string SourceColumn, string DestinationColumn);
public sealed record BulkWriteTarget(string TableName, IReadOnlyList<ColumnMap> Columns);
public sealed record BulkWriteOptions(int BatchSize, int TimeoutSeconds);
public sealed record BulkWriteContext(DbConnection Connection, DbTransaction Transaction, BulkWriteOptions Options, ILoggerFactory LoggerFactory);

public static class BulkCopyErrorMessages
{
    public const string ColumnMappingMismatch =
        "The given column mappings does not match up with any column in the destination table.";
    public const string ExternalTransactionCompleted =
        "The supplied transaction has already been committed or rolled back.";
    public static string SourceColumnNotFound(string column) =>
        $"The mapped source column '{column}' does not exist in the data being copied.";
}
```
How Postgres would fit later: `CreateConnection` → `NpgsqlConnection`. `CreateWriter` → a writer doing `BeginBinaryImportAsync("COPY t (cols) FROM STDIN (FORMAT BINARY)")`, `WriteRowAsync` per reader row, then `CompleteAsync`. It runs inside the connection's transaction. Documented caveat for that release: a failed COPY puts the caller's transaction into the aborted state (25P02). That is database behaviour, not Loki's.

```csharp
namespace Loki.BulkDataProcessor.Pipeline;

internal sealed class ConnectionScope : IAsyncDisposable
{
    private readonly ILogger _logger;

    private ConnectionScope(DbConnection connection, DbTransaction transaction, bool ownsTransaction, ILogger logger)
    {
        Connection = connection;
        Transaction = transaction;
        OwnsTransaction = ownsTransaction;
        _logger = logger;
    }

    public DbConnection Connection { get; }
    public DbTransaction Transaction { get; }
    public bool OwnsTransaction { get; }

    public static async Task<ConnectionScope> OpenAsync(IBulkCopyProvider provider, BulkCallSettings settings,
        ILogger logger, CancellationToken cancellationToken)
    {
        if (settings.ExternalTransaction is not null)
        {
            return Adopt(provider, settings.ExternalTransaction, logger);
        }

        DbConnection connection = provider.CreateConnection(settings.ConnectionString);
        try
        {
            await connection.OpenAsync(cancellationToken).ConfigureAwait(false);
            DbTransaction transaction = await connection.BeginTransactionAsync(cancellationToken).ConfigureAwait(false);
            return new ConnectionScope(connection, transaction, ownsTransaction: true, logger);
        }
        catch
        {
            await connection.DisposeAsync().ConfigureAwait(false);   // #13: no leak if Open/Begin fails
            throw;
        }
    }

    private static ConnectionScope Adopt(IBulkCopyProvider provider, IDbTransaction external, ILogger logger)
    {
        DbTransaction transaction = provider.AdoptExternalTransaction(external);
        DbConnection connection = transaction.Connection
            ?? throw new InvalidOperationException(BulkCopyErrorMessages.ExternalTransactionCompleted);
        return new ConnectionScope(connection, transaction, ownsTransaction: false, logger);
    }

    /// <summary>Commits only Loki's own transaction. Not cancellable once the write has succeeded.</summary>
    public Task CompleteAsync() =>
        OwnsTransaction ? Transaction.CommitAsync(CancellationToken.None) : Task.CompletedTask;

    /// <summary>Never throws, so the original failure is always the one that surfaces (#12).</summary>
    public async Task RollbackAfterFailureAsync()
    {
        if (!OwnsTransaction)
        {
            _logger.LogWarning("Bulk copy failed inside a caller-owned transaction; it was left for the caller to commit or roll back");
            return;
        }

        try
        {
            await Transaction.RollbackAsync(CancellationToken.None).ConfigureAwait(false);
        }
        catch (Exception rollbackException)
        {
            _logger.LogError(rollbackException, "Rolling back the internal transaction failed; the original bulk copy error is rethrown");
        }
    }

    public async ValueTask DisposeAsync()
    {
        if (!OwnsTransaction)
        {
            return;   // caller owns the transaction and its connection
        }

        await Transaction.DisposeAsync().ConfigureAwait(false);
        await Connection.DisposeAsync().ConfigureAwait(false);
    }
}
```
```csharp
internal sealed class BulkCopyPipeline(IBulkCopyProvider provider, ILoggerFactory loggerFactory)
{
    private readonly ILogger<BulkCopyPipeline> _logger = loggerFactory.CreateLogger<BulkCopyPipeline>();

    public async Task ExecuteAsync(IDataReader source, BulkWriteTarget target, BulkCallSettings settings, CancellationToken cancellationToken)
    {
        await using ConnectionScope scope = await ConnectionScope
            .OpenAsync(provider, settings, _logger, cancellationToken).ConfigureAwait(false);
        try
        {
            await WriteAsync(scope, source, target, settings, cancellationToken).ConfigureAwait(false);
            await scope.CompleteAsync().ConfigureAwait(false);
        }
        catch
        {
            await scope.RollbackAfterFailureAsync().ConfigureAwait(false);
            throw;
        }
    }

    private async Task WriteAsync(ConnectionScope scope, IDataReader source, BulkWriteTarget target,
        BulkCallSettings settings, CancellationToken cancellationToken)
    {
        BulkWriteContext context = new(scope.Connection, scope.Transaction,
            new BulkWriteOptions(settings.BatchSize, settings.TimeoutSeconds), loggerFactory);
        await using IBulkWriter writer = provider.CreateWriter(context);
        try
        {
            await writer.WriteAsync(source, target, cancellationToken).ConfigureAwait(false);
        }
        catch (Exception exception) when (exception is not OperationCanceledException && !cancellationToken.IsCancellationRequested)
        {
            Exception translated = provider.TranslateException(exception, target);
            if (ReferenceEquals(translated, exception))
            {
                throw;
            }
            throw translated;   // InnerException == original (#15)
        }
    }
}
```

**Sources and the mapping rule (#16)**
```csharp
namespace Loki.BulkDataProcessor.Mappings.Resolution;

internal static class MappingKey
{
    /// <summary>A DataMapping matches the input's source name. With no source name, the destination table name is used.</summary>
    public static string For(string sourceName, string destinationTableName) =>
        string.IsNullOrWhiteSpace(sourceName) ? destinationTableName : sourceName;
}

internal static class ColumnMapResolver
{
    public static IReadOnlyList<ColumnMap> Resolve(AbstractMapping mapping, IReadOnlyList<string> sourceColumns) =>
        mapping is null
            ? sourceColumns.Select(column => new ColumnMap(column, column)).ToArray()
            : mapping.MappingInfo.MappingMetaDataCollection
                .Select(meta => new ColumnMap(meta.SourceColumn, meta.DestinationColumn)).ToArray();
}
```
```csharp
namespace Loki.BulkDataProcessor.Sources;

internal sealed class BulkSource : IDisposable
{
    private readonly bool _ownsReader;

    private BulkSource(IDataReader reader, IReadOnlyList<ColumnMap> columns, bool ownsReader)
    {
        Reader = reader;
        Columns = columns;
        _ownsReader = ownsReader;
    }

    public IDataReader Reader { get; }
    public IReadOnlyList<ColumnMap> Columns { get; }

    public static BulkSource FromModels<T>(IEnumerable<T> models, MappingRegistry mappings) where T : class
    {
        string[] properties = typeof(T).GetPublicPropertyNames();
        AbstractModelMapping mapping = mappings.Models.GetMappingFor(typeof(T));
        return new BulkSource(ObjectReader.Create(models, properties), ColumnMapResolver.Resolve(mapping, properties), ownsReader: true);
    }

    public static BulkSource FromDataTable(DataTable table, string destinationTableName, MappingRegistry mappings)
    {
        DataMapping mapping = mappings.Data.GetMappingFor(MappingKey.For(table.TableName, destinationTableName));
        string[] columns = table.Columns.Cast<DataColumn>().Select(column => column.ColumnName).ToArray();
        return new BulkSource(table.CreateDataReader(), ColumnMapResolver.Resolve(mapping, columns), ownsReader: true);
    }

    public static BulkSource FromDataReader(IDataReader reader, string destinationTableName, string sourceName, MappingRegistry mappings)
    {
        DataMapping mapping = mappings.Data.GetMappingFor(MappingKey.For(sourceName, destinationTableName));
        string[] columns = Enumerable.Range(0, reader.FieldCount).Select(reader.GetName).ToArray();
        return new BulkSource(reader, ColumnMapResolver.Resolve(mapping, columns), ownsReader: false);   // caller owns it
    }

    public static BulkSource FromJson(JsonDataReader reader, MappingRegistry mappings) =>
        FromOwnedReader(reader, reader.TableName, mappings);

    private static BulkSource FromOwnedReader(IDataReader reader, string destinationTableName, MappingRegistry mappings)
    {
        BulkSource borrowed = FromDataReader(reader, destinationTableName, sourceName: null, mappings);
        return new BulkSource(reader, borrowed.Columns, ownsReader: true);
    }

    public void Dispose()
    {
        if (_ownsReader)
        {
            Reader.Dispose();
        }
    }
}
```

```csharp
    public IDbTransaction Transaction
    {
        get => _settings.ExternalTransaction;
        set
        {

            {

            _settings.SetTransaction(value);

    public Task SaveAsync<T>(IEnumerable<T> dataToProcess, string destinationTableName, CancellationToken cancellationToken = default) where T : class
    {
        dataToProcess.ThrowIfCollectionIsNullOrEmpty(nameof(dataToProcess));
        destinationTableName.ThrowIfNullOrEmptyString(nameof(destinationTableName));
        return ExecuteAsync(() => BulkSource.FromModels(dataToProcess, _mappings), destinationTableName, cancellationToken);
    }

    public Task SaveAsync(DataTable dataTable, string destinationTableName, CancellationToken cancellationToken = default)
    {
        destinationTableName.ThrowIfNullOrEmptyString(nameof(destinationTableName));
        dataTable.ThrowIfNullOrHasZeroRows();
        return ExecuteAsync(() => BulkSource.FromDataTable(dataTable, destinationTableName, _mappings), destinationTableName, cancellationToken);
    }

    public Task SaveAsync(IDataReader dataReader, string destinationTableName, CancellationToken cancellationToken = default) =>
        SaveAsync(dataReader, destinationTableName, sourceName: null, cancellationToken);

    public Task SaveAsync(IDataReader dataReader, string destinationTableName, string sourceName, CancellationToken cancellationToken = default)
    {
        dataReader.ThrowIfNull(nameof(dataReader));
        destinationTableName.ThrowIfNullOrEmptyString(nameof(destinationTableName));
        return ExecuteAsync(() => BulkSource.FromDataReader(dataReader, destinationTableName, sourceName, _mappings), destinationTableName, cancellationToken);
    }

    public async Task SaveAsync(Stream jsonStream, CancellationToken cancellationToken = default)
    {
        jsonStream.ThrowIfNull(nameof(jsonStream));
        using JsonDocument document = await JsonDocument.ParseAsync(jsonStream, cancellationToken: cancellationToken).ConfigureAwait(false);
        JsonDataReader reader = JsonDataReader.Create(document, _logger);
        reader.TableName.ThrowIfNullOrEmptyString("tableName");
        await ExecuteAsync(() => BulkSource.FromJson(reader, _mappings), reader.TableName, cancellationToken).ConfigureAwait(false);
    }

    private async Task ExecuteAsync(Func<BulkSource> createSource, string destinationTableName, CancellationToken cancellationToken)
    {
        BulkCallSettings settings = _settings.Snapshot(_connectionString);
        _logger.LogInformation("Starting bulk copy to {TableName} via {Provider}", destinationTableName, _provider.Name);
        try
        {
            using BulkSource source = createSource();
            BulkWriteTarget target = new(destinationTableName, source.Columns);
            await _pipeline.ExecuteAsync(source.Reader, target, settings, cancellationToken).ConfigureAwait(false);
            _logger.LogInformation("Completed bulk copy to {TableName} via {Provider}", destinationTableName, _provider.Name);
        }
        catch (Exception exception)
        {
            _logger.LogError(exception, "Bulk copy to {TableName} via {Provider} failed", destinationTableName, _provider.Name);
            throw;
        }
    }
}
```

```csharp
namespace Loki.BulkDataProcessor.Internal;

internal sealed class BulkProcessorFactory : IBulkProcessorFactory
{
    private readonly IReadOnlyDictionary<string, IBulkCopyProvider> _providers;
    private readonly MappingRegistry _mappings;
    private readonly ILoggerFactory _loggerFactory;

    public BulkProcessorFactory(IEnumerable<IBulkCopyProvider> providers, MappingRegistry mappings, LokiLogging logging)
    {
        _providers = IndexByName(providers);
        _mappings = mappings;
        _loggerFactory = logging.LoggerFactory;
    }

    public IReadOnlyCollection<string> ProviderNames => _providers.Keys.ToArray();

    public bool HasProvider(string providerName) => providerName is not null && _providers.ContainsKey(providerName);

    public IBulkProcessor Create(string providerName, string connectionString)
    {
        providerName.ThrowIfNullOrEmptyString(nameof(providerName));
        connectionString.ThrowIfNullOrEmptyString(nameof(connectionString));
        if (!_providers.TryGetValue(providerName, out IBulkCopyProvider provider))
        {
            throw new ArgumentException(
                $"No bulk copy provider named '{providerName}' is registered. Registered: {string.Join(", ", _providers.Keys)}.",
                nameof(providerName));
        }
        return new BulkProcessor(provider, connectionString, _mappings, _loggerFactory);
    }

    private static Dictionary<string, IBulkCopyProvider> IndexByName(IEnumerable<IBulkCopyProvider> providers)
    {
        Dictionary<string, IBulkCopyProvider> byName = new(StringComparer.OrdinalIgnoreCase);
        foreach (IBulkCopyProvider provider in providers)
        {
            if (!byName.TryAdd(provider.Name, provider))
            {
                throw new InvalidOperationException($"Bulk copy provider '{provider.Name}' is registered more than once.");
            }
        }
        return byName;
    }
```

```csharp
internal sealed class ArrayBindOracleWriter(OracleConnection connection, BulkWriteOptions options,
    IOracleIdentifierResolver resolver, OracleTypeMap typeMap) : IBulkWriter
{
    internal const int DefaultChunkSize = 5000;   // BatchSize 0 ("all rows") would need everything in memory, so 0 → 5000

    public async Task WriteAsync(IDataReader source, BulkWriteTarget target, CancellationToken cancellationToken)
    {
        OracleResolvedTarget resolved = await resolver.ResolveAsync(connection, target, cancellationToken).ConfigureAwait(false);
        OracleBoundColumn[] columns = BindColumns(source, resolved);
        using OracleCommand command = CreateInsertCommand(resolved, columns);
        ColumnBuffer buffer = new(columns.Length, options.BatchSize > 0 ? options.BatchSize : DefaultChunkSize);

        while (source.Read())
        {
            buffer.AddRow(source, columns);
            if (buffer.IsFull)
            {
                await FlushAsync(command, buffer, cancellationToken).ConfigureAwait(false);
            }
        }

        if (buffer.Count > 0)
        {
            await FlushAsync(command, buffer, cancellationToken).ConfigureAwait(false);
        }
    }

    private OracleBoundColumn[] BindColumns(IDataReader source, OracleResolvedTarget resolved) =>
        resolved.Columns.Select(column =>
        {
            int ordinal = SourceOrdinal(source, column.SourceColumn);
            OracleBinding binding = typeMap.For(source.GetFieldType(ordinal), column.SourceColumn);
            return new OracleBoundColumn(ordinal, binding);
        }).ToArray();

    private static int SourceOrdinal(IDataReader source, string column)
    {
        int ordinal;
        try { ordinal = source.GetOrdinal(column); }
        catch (IndexOutOfRangeException) { ordinal = -1; }
        return ordinal >= 0 ? ordinal : throw new InvalidOperationException(BulkCopyErrorMessages.SourceColumnNotFound(column));
    }

    private OracleCommand CreateInsertCommand(OracleResolvedTarget resolved, OracleBoundColumn[] columns)
    {
        OracleCommand command = connection.CreateCommand();
        command.CommandText = OracleInsertSqlBuilder.Build(resolved);   // INSERT INTO T (A, B) VALUES (:1, :2)
        command.BindByName = false;
        command.CommandTimeout = options.TimeoutSeconds;               // per chunk execution
        foreach (OracleBoundColumn column in columns)
        {
            command.Parameters.Add(new OracleParameter { OracleDbType = column.Binding.DbType, Direction = ParameterDirection.Input });
        }
        return command;
    }

    private static async Task FlushAsync(OracleCommand command, ColumnBuffer buffer, CancellationToken cancellationToken)
    {
        command.ArrayBindCount = buffer.Count;
        for (int i = 0; i < command.Parameters.Count; i++)
        {
            command.Parameters[i].Value = buffer.ValuesFor(i);          // array length == ArrayBindCount
        }
        await command.ExecuteNonQueryAsync(cancellationToken).ConfigureAwait(false);
        buffer.Clear();
    }

    public ValueTask DisposeAsync() => ValueTask.CompletedTask;
}

internal sealed record OracleBoundColumn(int SourceOrdinal, OracleBinding Binding);

internal sealed class ColumnBuffer
{
    private readonly object[][] _columns;
    private readonly int _capacity;

    public ColumnBuffer(int columnCount, int capacity)
    {
        _capacity = capacity;
        _columns = new object[columnCount][];
        for (int i = 0; i < columnCount; i++) _columns[i] = new object[capacity];
    }

    public int Count { get; private set; }
    public bool IsFull => Count == _capacity;

    public void AddRow(IDataRecord record, IReadOnlyList<OracleBoundColumn> columns)
    {
        for (int i = 0; i < columns.Count; i++)
        {
            OracleBoundColumn column = columns[i];
            _columns[i][Count] = record.IsDBNull(column.SourceOrdinal)
                ? DBNull.Value
                : column.Binding.Convert(record.GetValue(column.SourceOrdinal));
        }
        Count++;
    }

    public object[] ValuesFor(int column) => Count == _capacity ? _columns[column] : _columns[column][..Count];

    public void Clear()
    {
        foreach (object[] values in _columns) Array.Clear(values, 0, Count);   // release references between chunks
        Count = 0;
    }
}

internal static class OracleInsertSqlBuilder
{
    /// <remarks>Only identifiers already validated/quoted by an IOracleIdentifierResolver are concatenated; values are always bound.</remarks>
    public static string Build(OracleResolvedTarget target)
    {
        StringBuilder sql = new StringBuilder("INSERT INTO ").Append(target.QualifiedTableSql).Append(" (");
        sql.AppendJoin(", ", target.Columns.Select(column => column.DestinationSql)).Append(") VALUES (");
        sql.AppendJoin(", ", Enumerable.Range(1, target.Columns.Count).Select(i => $":{i}")).Append(')');
        return sql.ToString();
    }
}
```

```csharp
internal sealed class DirectPathOracleWriter(OracleConnection connection, BulkWriteOptions options,
    IOracleIdentifierResolver resolver) : IBulkWriter
{
    public async Task WriteAsync(IDataReader source, BulkWriteTarget target, CancellationToken cancellationToken)

        cancellationToken.ThrowIfCancellationRequested();   // last cancellation point: WriteToServer is synchronous
        using OracleBulkCopy bulkCopy = CreateBulkCopy(resolved);
        bulkCopy.WriteToServer(source);                      // ODP.NET has no async direct-path API (documented limitation)
    }

    private OracleBulkCopy CreateBulkCopy(OracleResolvedTarget resolved)
    {
        OracleBulkCopy bulkCopy = new(connection, OracleBulkCopyOptions.Default)   // never UseInternalTransaction / EnforceIndexChecks
        {
            DestinationTableName = resolved.TableSql,
            BatchSize = options.BatchSize,
            BulkCopyTimeout = options.TimeoutSeconds
        };
        if (resolved.SchemaSql is not null)
        {
            bulkCopy.DestinationSchemaName = resolved.SchemaSql;
        }
        foreach (OracleResolvedColumn column in resolved.Columns)
        {
            bulkCopy.ColumnMappings.Add(new OracleBulkCopyColumnMapping(column.SourceColumn, column.DestinationSql));
        }
        return bulkCopy;
    }

    public ValueTask DisposeAsync() => ValueTask.CompletedTask;
}
```

```csharp
    private static readonly IReadOnlyDictionary<Type, OracleBinding> Bindings = new Dictionary<Type, OracleBinding>
    {
        [typeof(string)] = new(OracleDbType.Varchar2, AsIs),            // "" is stored as NULL (Oracle semantics, documented)
        [typeof(char)] = new(OracleDbType.Varchar2, value => value.ToString()),
        [typeof(byte)] = new(OracleDbType.Byte, AsIs),
        [typeof(short)] = new(OracleDbType.Int16, AsIs),
        [typeof(int)] = new(OracleDbType.Int32, AsIs),
        [typeof(long)] = new(OracleDbType.Int64, AsIs),
        [typeof(decimal)] = new(OracleDbType.Decimal, AsIs),
        [typeof(double)] = new(OracleDbType.BinaryDouble, AsIs),
        [typeof(float)] = new(OracleDbType.BinaryFloat, AsIs),
        [typeof(DateTime)] = new(OracleDbType.TimeStamp, AsIs),
        [typeof(DateTimeOffset)] = new(OracleDbType.TimeStampTZ, AsIs),
        [typeof(TimeSpan)] = new(OracleDbType.IntervalDS, AsIs),
        [typeof(Guid)] = new(OracleDbType.Raw, value => ((Guid)value).ToByteArray()),   // RAW(16), .NET byte order (same as direct path)
        [typeof(byte[])] = new(OracleDbType.Raw, AsIs),                                 // ≤ RAW limit; BLOB not supported by ArrayBind in 9.0
    };

    private readonly OracleBinding _boolean = booleanBinding == OracleBooleanBinding.Boolean
        ? new OracleBinding(OracleDbType.Boolean, AsIs)
        : new OracleBinding(OracleDbType.Int16, value => (bool)value ? (short)1 : (short)0);

    public OracleBinding For(Type fieldType, string sourceColumn)
    {
        Type type = Nullable.GetUnderlyingType(fieldType) ?? fieldType;
        if (type == typeof(bool)) return _boolean;
        if (type.IsEnum) return ForEnum(type);
        return Bindings.TryGetValue(type, out OracleBinding binding)
            ? binding
            : throw new NotSupportedException($"Column '{sourceColumn}' has type {type.Name}, which the Oracle array-bind writer does not support.");
    }

    private static OracleBinding ForEnum(Type enumType)
    {
        Type underlying = Enum.GetUnderlyingType(enumType);
        OracleDbType dbType = Bindings[underlying].DbType;
        return new OracleBinding(dbType, value => System.Convert.ChangeType(value, underlying, CultureInfo.InvariantCulture));
    }
}
```
Rules:
- Minimum supported version is 19c.
- Booleans bind as NUMBER 0/1 by default. `OracleBooleanBinding.Boolean` uses native BOOLEAN on 23ai.
- Implicit NUMBER→BOOLEAN conversion on 23ai is checked by an integration test. If it fails, the README tells 23ai BOOLEAN users to set `BooleanBinding = Boolean`. The default stays Number either way, because 19c has no BOOLEAN.
- A column typed `object` (for example a DataTable column of `typeof(object)`) throws `NotSupportedException` before anything is written.

**Identifiers (CWE-89)**
```csharp
internal static partial class OracleIdentifier
{
    [GeneratedRegex("^[A-Za-z][A-Za-z0-9_$#]{0,127}$", RegexOptions.CultureInvariant)]
    private static partial Regex SimpleIdentifier();

    public static string RequireSimple(string name, string role) =>
        name is not null && SimpleIdentifier().IsMatch(name)
            ? name
            : throw new ArgumentException(
                $"The {role} '{Shorten(name)}' is not a valid unquoted Oracle identifier (letter first, then letters, digits, _ $ #, max 128). " +
                "Use OracleIdentifierResolution.CatalogLookup for quoted mixed-case names.", role);

    /// <summary>Quotes an exact catalogue name. Oracle names can never contain a double quote or NUL.</summary>
    public static string Quote(string exactName) =>
        !string.IsNullOrEmpty(exactName) && exactName.Length <= 128 && exactName.IndexOfAny(['"', '\0']) < 0
            ? $"\"{exactName}\""
            : throw new ArgumentException("Invalid Oracle identifier returned from the catalogue.", nameof(exactName));

    public static (string Schema, string Table) Split(string qualifiedName)
    {
        string[] parts = qualifiedName.Split('.');
        return parts.Length switch
        {
            1 => (null, parts[0]),
            2 => (parts[0], parts[1]),
            _ => throw new ArgumentException($"'{Shorten(qualifiedName)}' must be 'TABLE' or 'SCHEMA.TABLE'.", nameof(qualifiedName))
        };
    }

    public static string StripQuotes(string name) =>
        name.Length > 1 && name[0] == '"' && name[^1] == '"' ? name[1..^1] : name;

    private static string Shorten(string value) => value is null ? "null" : value.Length <= 64 ? value : $"{value[..64]}…";
}

internal interface IOracleIdentifierResolver
{
    Task<OracleResolvedTarget> ResolveAsync(OracleConnection connection, BulkWriteTarget target, CancellationToken cancellationToken);
}

internal sealed record OracleResolvedColumn(string SourceColumn, string DestinationSql);

internal sealed record OracleResolvedTarget(string SchemaSql, string TableSql, IReadOnlyList<OracleResolvedColumn> Columns)
{
    public string QualifiedTableSql => SchemaSql is null ? TableSql : $"{SchemaSql}.{TableSql}";
}

internal sealed class UnquotedIdentifierResolver : IOracleIdentifierResolver
{
    public Task<OracleResolvedTarget> ResolveAsync(OracleConnection connection, BulkWriteTarget target, CancellationToken cancellationToken)
    {
        (string schema, string table) = OracleIdentifier.Split(target.TableName);
        OracleResolvedColumn[] columns = target.Columns
            .Select(column => new OracleResolvedColumn(column.SourceColumn, OracleIdentifier.RequireSimple(column.DestinationColumn, "destination column")))
            .ToArray();
        return Task.FromResult(new OracleResolvedTarget(
            schema is null ? null : OracleIdentifier.RequireSimple(schema, "schema"),
            OracleIdentifier.RequireSimple(table, "table name"),
            columns));
    }
}

internal sealed class CatalogIdentifierResolver : IOracleIdentifierResolver
{
    private const string CatalogQuery =
        "SELECT OWNER, TABLE_NAME, COLUMN_NAME FROM ALL_TAB_COLUMNS " +
        "WHERE UPPER(OWNER) = UPPER(NVL(:owner, SYS_CONTEXT('USERENV', 'CURRENT_SCHEMA'))) " +
        "AND UPPER(TABLE_NAME) = UPPER(:tableName)";

    public async Task<OracleResolvedTarget> ResolveAsync(OracleConnection connection, BulkWriteTarget target, CancellationToken cancellationToken)
    {
        (string schema, string table) = OracleIdentifier.Split(target.TableName);
        IReadOnlyList<CatalogRow> rows = await QueryAsync(connection,
            schema is null ? null : OracleIdentifier.StripQuotes(schema), OracleIdentifier.StripQuotes(table), cancellationToken).ConfigureAwait(false);
        (string owner, string tableName) = PickTable(rows, schema, table);
        string[] tableColumns = rows.Where(r => r.Owner == owner && r.Table == tableName).Select(r => r.Column).ToArray();
        OracleResolvedColumn[] columns = target.Columns
            .Select(c => new OracleResolvedColumn(c.SourceColumn, OracleIdentifier.Quote(PickName(tableColumns, c.DestinationColumn, "column"))))
            .ToArray();
        return new OracleResolvedTarget(OracleIdentifier.Quote(owner), OracleIdentifier.Quote(tableName), columns);
    }

    private static async Task<IReadOnlyList<CatalogRow>> QueryAsync(OracleConnection connection, string owner, string table, CancellationToken cancellationToken)
    {
        using OracleCommand command = connection.CreateCommand();
        command.CommandText = CatalogQuery;
        command.BindByName = true;
        command.Parameters.Add("owner", OracleDbType.Varchar2).Value = (object)owner ?? DBNull.Value;
        command.Parameters.Add("tableName", OracleDbType.Varchar2).Value = table;
        List<CatalogRow> rows = new();
        using DbDataReader reader = await command.ExecuteReaderAsync(cancellationToken).ConfigureAwait(false);
        while (await reader.ReadAsync(cancellationToken).ConfigureAwait(false))
        {
            rows.Add(new CatalogRow(reader.GetString(0), reader.GetString(1), reader.GetString(2)));
        }
        return rows;
    }

    private static (string Owner, string Table) PickTable(IReadOnlyList<CatalogRow> rows, string schema, string table)
    {
        string tableName = PickName(rows.Select(r => r.Table).Distinct().ToArray(), table, "table");
        string owner = PickName(rows.Where(r => r.Table == tableName).Select(r => r.Owner).Distinct().ToArray(), schema ?? rows.FirstOrDefault()?.Owner, "schema");
        return (owner, tableName);
    }

    /// <summary>Exact match first, then a single case-insensitive match; otherwise a clear error. A quoted request matches exactly only.</summary>
    private static string PickName(IReadOnlyCollection<string> candidates, string requested, string role)
    {
        if (requested is null || candidates.Count == 0)
        {
            throw new InvalidOperationException($"The destination {role} was not found or is not visible to the connected user.");
        }
        bool exactOnly = requested.Length > 1 && requested[0] == '"';
        string name = OracleIdentifier.StripQuotes(requested);
        string exact = candidates.FirstOrDefault(c => c == name);
        if (exact is not null || exactOnly)
        {
            return exact ?? throw new InvalidOperationException($"The destination {role} '{name}' was not found.");
        }
        string[] folded = candidates.Where(c => string.Equals(c, name, StringComparison.OrdinalIgnoreCase)).ToArray();
        return folded.Length == 1
            ? folded[0]
            : throw new InvalidOperationException(folded.Length == 0
                ? $"{BulkCopyErrorMessages.ColumnMappingMismatch} ('{name}' not found)"
                : $"The {role} '{name}' matches more than one object case-insensitively; quote it to choose exactly.");
    }

    private sealed record CatalogRow(string Owner, string Table, string Column);
}
```

### Security implications
- **CWE-89 (Oracle):** the table name can come from a JSON payload, so it is never trusted.
  - In Unquoted mode, every name part must match `^[A-Za-z][A-Za-z0-9_$#]{0,127}$` before any SQL is built. Values are always bound, never concatenated.
  - In CatalogLookup mode, caller names only appear as bind variables, and only catalogue names (rejected if they contain `"` or NUL) are quoted into SQL.
  - Unit tests feed injection strings such as `X; DROP TABLE Y`, `A"B`, `a.b.c`, 129 characters, Unicode and whitespace.
- **SQL Server table names:** `SqlBulkCopy` parses and brackets `DestinationTableName` itself, which is unchanged. Note for consumers (README): a JSON payload's `tableName` chooses the target table, so callers must decide which tables a payload is allowed to write to. This matters for Seedr, where tables are user-driven.
- **Secrets:**
  - The public `IBulkProcessor.ConnectionString` getter is removed.
  - `BulkCallSettings` is a non-record struct with `[DebuggerBrowsable(Never)]` and a redacting `ToString`.
  - Connection strings never appear in logs or exception messages; error messages list provider names only.
- **Driver messages:** the inner exception is now preserved (#15). The outer message still passes the driver text through, as before. SQL Server duplicate-key errors include key values (`The duplicate key value is (5)`). This is pre-existing behaviour; it is called out in the README so hosts don't surface it to end users. Loki's own messages never contain row data.
- **Transactions:** Loki never rolls back, commits or disposes a caller's transaction or connection (#12). It never opts into `UseInternalTransaction`/`EnforceIndexChecks`; the spike showed `EnforceIndexChecks` hanging and ignoring the timeout.
- **Direct-path integrity hazards:** FKs are not enforced and duplicate PKs make the index unusable. This is opt-in only, with prominent XML-doc and README warnings. The default array-bind path has the same integrity as `SqlBulkCopy` with `CheckConstraints|KeepNulls`.
- **TLS:** `Microsoft.Data.SqlClient` defaults to `Encrypt=true`, which is a security improvement. The upgrade guide tells dev users to set `TrustServerCertificate=true` explicitly and not to disable encryption.
- **Supply chain:** Testcontainers and the Docker client tree are gone from consumer graphs (#17), enforced by a CI check. The deprecated `System.Data.SqlClient` is removed.
- **Logging:** Loki no longer replaces the host's `ILoggerFactory` or adds console logging to the whole app.
